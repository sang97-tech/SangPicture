  • 사진 이동 시 썸네일 자동 스크롤 개선: 목록 끝에서 사진을 넘기면 약 5장씩 스크롤되어 연속 탐색이 편해졌습니다.

핵심 기능

반복되는 사진 작업을 가볍게

사진 이동부터 자르기, 회전, 밝기 조절까지 한 화면에서 빠르게.

여러 사진을 빠르게 편집

A / D 키로 이동, 회전하고 영역을 선택한 뒤 Space로 자르기! 밝기도 한 화면에서 모두 설정할 수 있습니다.

영역 선택 → Space

자르기

제거할 픽셀 수를 직접 입력하거나, 자르기 영역을 드래그해서 조절하세요. 비율을 고르고 Space / Enter로 확정!

Q : 위치 설정 · E : ON / OFF

십자선 보이기

Q 키로 마우스 위치에 십자선 설정, E 키로 켜고 끄기. 사진의 수평을 맞출 때 편리합니다.

회전 · 각도 조절
F : 좌우 · X : 상하

회전과 반전

90° 버튼이나 각도 입력으로 회전. 회색 여백을 드래그해 미세하게 조절할 수도 있습니다. F는 좌우, X는 상하 반전!

원본
밝기 조절 예시

밝기 조절

슬라이더를 움직이거나 숫자를 입력해 밝기 조절. ‘미세 조정’을 체크하면 대조와 중간톤도 따로 설정할 수 있습니다.

여러 장 선택 · 편집 → Ctrl + S

여러 장 편집하고 일괄 저장

Ctrl / Shift + 클릭으로 여러 장 선택. 함께 편집하거나 사진마다 편집한 뒤 Ctrl + S로 수정한 사진 모두 저장!

원본을 덮어씁니다. 보관하려면 ‘저장 전 원본 백업’을 체크하세요. 자르기는 먼저 확정!

MY LOGO 내 로고 워터마크 · 예시

워터마크 추가

‘Settings’에서 로고 이미지와 위치·크기를 설정하고 ‘워터마크 추가’를 클릭. 선택한 사진에 내 로고를 넣을 수 있습니다.

이름 바꾸기 F2 삭제 Delete 속성

사진 파일 정리

썸네일을 오른쪽 클릭해 이름 변경, 삭제, 속성 확인. F2로 이름을 바꾸고, Delete로 휴지통에 보낼 수 있습니다.

단축키 전체 보기

사진 영역을 클릭한 뒤 사용하세요. 숫자 입력 중 Enter / Space는 입력값을 확정합니다.
